# Java Airline Seat Booking Application

## Project Overview
A console-based airline seat booking application developed in Java as part of programming practice at the University of Westminster.

## Features
- Interactive menu for booking tickets and viewing seats.
- Displays available and occupied seats.
- Uses multidimensional arrays to manage seating arrangements.
- Prevents booking an already occupied seat.
- Displays ticket prices for different rows.

## Technologies Used
- Java
- Scanner
- Multidimensional Arrays
- Methods, Loops and Conditional Statements

## Skills Demonstrated
- Java programming fundamentals
- Array manipulation
- Console input and output
- Modular programming
- Basic exception handling
